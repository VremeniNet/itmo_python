О приложении

Версия: {{ app.version }} Автор: {{ app.author.name }} ({{ app.author.group }})

Приложение получает актуальные курсы валют через функцию get_currencies и сохраняет выборочные значения в базе данных SQLite. Работа с БД инкапсулирована в контроллере CurrencyController, который реализует операции create / read / update / delete.

Через веб-интерфейс можно просмотреть список пользователей и их подписки, таблицу валют, а также выполнить обновление и удаление записей «Валюты»).
